This project predicts crop yield using machine learning techniques based on various input features like rainfall, temperature, area, production, and crop type. It helps farmers and agricultural stakeholders make informed decisions for better planning and production.
- Features
Machine Learning model trained on a Kaggle dataset
Achieved 97.03% accuracy
Simple web interface built with HTML and Flask
End-to-end implementation: preprocessing, model training, web app integration
- Technologies Used
Python
Scikit-learn
Pandas, NumPy
Flask
HTML/CSS
Google Colab (for training)
VS Code (for development)
- Project Structure
├── app.py                # Flask backend
├── templates/
│   └── index.html        # HTML frontend
├── model.pkl             # Trained ML model
├── static/               # CSS or image files (if any)
├── dataset.csv           # Dataset used for training
└── README.md             # Project documentation
- Dataset
Sourced from Kaggle: Crop yield dataset with features like rainfall, area, production, crop type, etc.
